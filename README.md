# LaraMonster downloads

LaraMonster is a local PHP & Laravel development environment for **Linux, macOS and Windows**: sites on `.test`, every PHP version, HTTPS, MySQL / PostgreSQL / Redis / Mailpit / Meilisearch, a mail inbox and a new-project wizard. It's free.

**LaraMonster Pro** adds the Event Tracker and Jobs & Queues → [monstersgate.com/laramonster](https://monstersgate.com/laramonster)

## Download

Get the latest version from **[Releases](https://github.com/MahmoudAdelMansour/laramonster-releases/releases/latest)**:

| System | File |
|---|---|
| Windows 10/11 | `LaraMonster-windows-amd64.exe` |
| macOS 11+ (Apple Silicon and Intel) | `LaraMonster-macos-universal.zip` |
| Linux (x86-64) | `LaraMonster-linux-amd64.tar.gz`: unpack, then run `./install.sh` |

The app tells you when a new version is out. This repository only holds the downloads.
